Confidentialité · Version du 26 septembre 2026

Vos émotions ne sont pas nos données.

Cette première version est un site statique sans compte utilisateur ni formulaire de collecte émotionnelle. Elle ne crée pas de profil, ne transmet pas vos réponses à un formateur et n'intègre ni publicité ni outil d'analyse de votre comportement.

Le parcours de vos données

Lecture du site

Votre navigateur télécharge des fichiers statiques hébergés par GitHub Pages. GitHub peut traiter les informations techniques de connexion nécessaires à son service, selon sa propre documentation.

Exercice

Les questions sont imprimables et ne comportent aucun formulaire de saisie ou d'enregistrement de réponses personnelles. Aucun résultat n'est envoyé à Muze-X, à Capévol ou au Département.

Recherche dans le catalogue

Le filtrage des ressources, de l’atlas des pensées et du centre de recherche se fait localement dans votre navigateur. Le terme recherché n'est pas enregistré ni transmis à notre serveur : le catalogue JSON public est téléchargé avec la page.

Contribution volontaire

Si vous ouvrez GitHub pour proposer une ressource ou une modification, votre compte et le contenu envoyé relèvent de GitHub. Les issues et pull requests du dépôt public sont visibles par tous.

Site tiers

En cliquant sur une vidéo, une publication ou un autre lien externe, vous consultez un autre opérateur. Aucun lecteur tiers n'est chargé automatiquement sur ce site.

Champ de réflexion émotionnelle

Le champ visuel utilise uniquement la mémoire temporaire de votre navigateur : position instantanée du cercle, mouvements des particules, commandes et position du pointeur pendant le geste. Aucun historique, score émotionnel, diagnostic, compte, cookie ou stockage applicatif. Ces informations ne sont ni transmises au projet, ni communiquées à Capévol ou à un autre organisme. Le champ reste fixe tant que vous n'avez pas choisi de démarrer son animation.

Les fichiers de la page sont téléchargés depuis GitHub Pages, qui peut traiter séparément des informations techniques de connexion ; cette limite figure dans la présente notice.

Cookies et stockage

Notre code n'ajoute ni cookie, ni stockage local de vos réponses, ni pixel de suivi, ni analytics. Nous ne contrôlons pas les traitements techniques de GitHub Pages ou des services externes que vous décidez de consulter. Aucun média externe n'est intégré par défaut.

Vos droits

Le RGPD prévoit, selon la situation et les exceptions légales, des droits d'information, d'accès, de rectification, d'effacement, de limitation, d'opposition et de portabilité. Les droits relatifs aux décisions automatisées peuvent également être pertinents pour d'autres services ; notre site n'effectue aucune décision de ce type.

Comprendre et exercer vos droits : CNIL ↗

À qui vous adresser ?

GitHub : pour les données de compte et d'hébergement, consulter sa politique de confidentialité ↗ et ses moyens d'exercice des droits.

Une contribution publiée dans notre dépôt : vous pouvez modifier votre contribution lorsque GitHub le permet, ou signaler à l'éditeur Muse-IRS une issue problématique en ne fournissant que son lien ou son numéro. Une issue est publique : n'y envoyez jamais d'information intime, de pièce administrative ou de justificatif d'identité. Pour une urgence confidentielle, utilisez les mécanismes privés de signalement proposés par GitHub lorsqu'ils sont disponibles ; aucun canal confidentiel propre au projet n'est actuellement annoncé.

Une ressource hébergée ailleurs : exercez vos droits auprès de l'opérateur de ce site, qui détermine ses propres traitements.

Une suppression sur ce dépôt n'efface pas nécessairement les copies, caches, forks ou l'historique Git. Nous ne promettons pas l'effacement de contenus que nous ne contrôlons pas.

Édition et responsabilité. Contenu publié par le compte GitHub Muse-IRS ↗ ; hébergement prévu par GitHub Pages. L'identité juridique et le canal confidentiel de contact de l'éditeur doivent être précisés avant toute fonction de collecte directe ou diffusion institutionnelle formalisée. Cette notice n'affirme pas que les traitements opérés par les services tiers relèvent de notre contrôle.
